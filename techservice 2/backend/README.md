# Back-end — Iteração 1

Implementação em Python/Flask, com SQLite.

- `controller.py`: rotas HTTP, sessão de acesso, proteção CSRF e respostas.
- `service.py`: validações e regras do atendimento.
- `repository.py`: consultas parametrizadas, transações e persistência.
- `../app.py`: ponto de entrada do servidor.

Um único funcionário de demonstração utiliza todas as funções. Perfis separados e cadastro de usuários ficam para iterações futuras.
