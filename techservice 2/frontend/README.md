# Front-end — Iteração 1

Interface web responsiva renderizada pelo Flask/Jinja.

O arquivo `templates/app.html` contém as telas de login, painel, clientes, equipamentos, abertura de OS, consulta, acompanhamento e histórico. O CSS está incluído no próprio template e não depende de serviços externos.

Não é um site estático: precisa do servidor Python e do banco SQLite. GitHub Pages não executa esta aplicação.
